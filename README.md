# Age of a Fossil Prediction

## Deskripsi
Proyek ini bertujuan untuk memprediksi usia fosil berdasarkan berbagai fitur geologis dan kimia menggunakan model **Linear Regression**. Model ini dikembangkan dengan pendekatan pembelajaran mesin untuk memberikan estimasi akurat terhadap usia fosil.

## Dataset
Dataset yang digunakan berisi beberapa fitur yang berkaitan dengan karakteristik fosil, seperti:
- Kandungan karbon
- Kandungan oksigen
- Kedalaman penemuan
- Komposisi mineral
- dsb
